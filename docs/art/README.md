# 그래픽 제작 워크플로우

게임성은 같고 그래픽만 다른 **스킨 두 가지**를 지원한다. 메인 화면의 "그래픽" 버튼이나 주소 뒤의 `?skin=svg`, `?skin=image`로 바꾼다.

| 스킨 | 내용 | 위치 |
|---|---|---|
| `svg` (기본) | Claude가 코드로 그린 벡터 그림 50개 (타워 18, 적 10, 영웅 2, 병사, 건설 자리, 투사체 3, 소품 15) | `public/skins/svg/` (생성: `npm run gen:svg`, 원본: `scripts/gen-svg-skin.cjs`) |
| `image` | 이미지 생성 AI(Gemini, ChatGPT 등)로 만든 PNG | `public/skins/image/` (생성: `npm run assets`) |

`image` 스킨에 없는 그림은 `svg` 스킨 그림으로, 거기에도 없으면 코드 도형으로 대신 그린다. 그래서 이미지를 일부만 만들어도 게임이 깨지지 않는다.

아래는 `image` 스킨용 이미지를 만드는 순서다 (ChatGPT뿐 아니라 Gemini 등 어떤 이미지 생성 서비스에도 같은 프롬프트를 쓴다).

## 파일 구성
| 파일 | 용도 |
|---|---|
| `docs/art/prompts.md` | ChatGPT에 붙여넣을 프롬프트 60개 (스타일 가이드 + 에셋별) |
| `docs/art/manifest.json` | 에셋 목록: key, 분류, 최종 크기, 우선순위, 설명. 후처리 스크립트와 게임 코드가 읽는다 |
| `assets-inbox/` | ChatGPT 원본 이미지를 넣는 곳 |
| `scripts/process-assets.py` | 원본 → 게임용 PNG 변환 (`public/skins/image/`에 출력) |
| `public/skins/image/` | 변환된 게임용 이미지 (게임이 불러온다) |

## 만드는 순서
1. `prompts.md`의 **0. 스타일 가이드**를 새 ChatGPT 대화에 붙여넣는다. 분류별로 대화를 따로 만든다 (타워 / 적 / 영웅 / 타일 / 소품).
2. **P1 우선순위부터** 에셋별 프롬프트를 하나씩 붙여넣어 만든다. 첫 결과가 마음에 들면 그 이미지를 첨부해서 "이 이미지를 스타일 기준으로 써줘"라고 말하고 나머지를 만든다.
3. 결과가 마음에 안 들면 같은 대화에서 "배경은 단색 마젠타 #FF00FF 유지, 외곽선을 더 굵게" 같은 식으로 고쳐 달라고 한다.
4. 이미지를 내려받고 **파일 이름을 key로 바꾼다**: `t_archer_1.png`, `e_goblin.png`, `h_knight.png` … (정확히 `manifest.json`의 key). 확장자는 png 권장.
5. 파일을 `assets-inbox/`에 넣는다 (하위 폴더로 나눠도 된다).

## 저장소에 올리는 방법
- **GitHub 웹에서 올리기 (가장 쉬움):** 저장소 → `assets-inbox` 폴더 → `Add file` → `Upload files`로 끌어다 놓고 커밋한다. 한 번에 올릴 수 있는 파일은 100개 이하다. 커밋 대상 브랜치는 새 브랜치(예: `art-inbox`)를 만들어 올리면 안전하다.
- **로컬에서 올리기:** 폴더에 복사한 뒤 `git add assets-inbox && git commit -m "원본 에셋 추가" && git push`.
- 올린 뒤 Claude에게 이렇게 말하면 된다: **"assets-inbox에 이미지 올렸어. 게임에 적용해줘."** (올린 브랜치 이름도 알려준다.)
- 채팅창에 이미지를 직접 붙여 보내는 것은 한두 장 확인용으로만 쓰고, 대량 전달은 저장소에 올리는 방식이 확실하다.

## Claude가 하는 일 (참고)
1. `pip install pillow numpy` 후 `python3 scripts/process-assets.py`를 실행한다. 마젠타 배경 제거, 여백 자르기, 크기 맞춤이 자동으로 되고, 변환 개수·실패·누락 목록이 출력된다. 이름이 key와 다른 파일도 알려준다.
2. (게임 코드는 이미 연결되어 있다) 스킨 로더가 `public/skins/image/index.json`에 있는 이미지를 `image` 스킨으로 불러온다. 이미 코드는 연결되어 있어서 변환만 하면 바로 적용된다. 이미지가 없는 에셋은 SVG 그림을 그대로 쓴다.
3. 이미지는 화면 표시 크기의 **2배**로 만들어 두므로(고해상도 화면용) 코드에서 0.5배로 표시한다.
4. 스크린샷으로 확인하고 크기·위치를 조정한다.

## 규칙과 주의
- **방향:** 적, 영웅, 병사는 모두 **오른쪽을 보게** 만든다. 왼쪽으로 가는 경로에서는 좌우 반전한다.
- **배경:** 캐릭터·타워·소품은 **단색 마젠타(#FF00FF)** 배경. 타일(`g_*`, `r_*`)만 배경 없이 꽉 찬 이미지로 만든다. 피사체에 마젠타나 진한 분홍을 쓰지 않는다.
- **타워 레벨:** `t_<종류>_1`~`_3`이 레벨 1~3이다. 업그레이드하면 이미지가 바뀐다. 레벨 2, 3은 P2라서 나중에 만들어도 된다.
- **저작권:** 프롬프트에 "기존 게임을 모방하지 말 것"을 넣었다. 결과물이 특정 게임의 캐릭터와 너무 비슷하면 쓰지 말고 다시 만든다. ChatGPT가 만든 이미지의 상업적 사용 조건은 OpenAI 약관에서 확인한다.
- **타일 이음새:** ChatGPT가 완벽히 이어지는 타일을 못 만들 수 있다. 이음새가 보이면 Claude가 가장자리를 섞어 보정하거나, 타일 대신 코드로 그린 배경을 유지한다.
- **용량:** 원본은 PNG 한 장당 1~3MB 정도라 60장이면 100MB 안팎이다. 저장소 용량이 걱정되면 변환 후 원본을 구글 드라이브로 옮기고 `assets-inbox`에서 삭제해도 된다 (변환된 `public/assets`는 가볍다).

## Gemini에서 만들 때 (프롬프트는 그대로 써도 된다)
- 프롬프트는 영어 그대로 붙여넣는다. 한국어로 "배경을 단색 마젠타로 다시" 같은 수정 요청은 해도 된다.
- **워터마크:** Gemini 앱에서 만든 이미지의 오른쪽 아래에 작은 워터마크가 들어가는 경우가 있다. 변환 스크립트가 오른쪽 아래 12% x 12%를 지우므로, 피사체가 그 모서리에 닿지 않게 만든다. (워터마크 정책은 서비스가 바꿀 수 있으니 결과 이미지를 직접 확인한다.)
- **배경:** 정확한 #FF00FF를 못 지키고 연한 분홍/보라나 그라데이션이 나올 수 있다. 약간의 차이는 변환 때 처리되지만, 그림자나 바닥이 같이 그려지면 "배경은 완전히 평평한 단색 #FF00FF, 그림자 없음"으로 다시 요청한다.
- **일관성:** 같은 대화에서 만들고, 처음 마음에 든 이미지를 첨부해 "이 이미지와 같은 스타일로"라고 요청한다.
- **한 장에 한 개체:** 여러 개체를 한 장에 모아 달라고 하면 잘라내기가 어렵다.
- 무료 사용량과 상업적 이용 조건은 서비스 약관에서 직접 확인한다.
