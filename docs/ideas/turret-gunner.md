# 새 게임 컨셉: 포대 사수 슈팅 (가제)

> 2026-11-21 사용자 아이디어 메모. 자세한 설명은 사용자가 나중에 다시 해 주기로 함. 아직 구현 계획 없음.
> Realm Guard(타워 디펜스)와는 별개의 게임이다.

## 핵심
- 플레이어는 **포대의 사수**가 되어 날아오는 **포탄**이나 **적**을 쏘아 맞힌다.
- 화면을 **4분할**해서 쓴다. (각 구역이 무엇인지 — 방향별 포대인지, 조준 구역인지 등 — 는 미정)

## 무기
- 기본 무기: **기관총** (연사). **기관포**(기관포탄)일 수도 있음.
- 특수 무기: **미사일**.

## 아직 정할 것 (사용자 설명 대기)
- 4분할 화면의 의미와 조작 방법 (마우스/터치로 구역 선택? 구역마다 포대?)
- 적 종류(비행기, 미사일, 포탄 등)와 웨이브 구성
- 미사일 사용 제한(탄약, 쿨다운), 기관총 과열 여부
- 승패 조건, 스테이지 구성, 수익 모델(Realm Guard처럼 광고?)
- 스택(Realm Guard처럼 TypeScript + Phaser 3 + Vite 정적 웹게임으로 갈지)
